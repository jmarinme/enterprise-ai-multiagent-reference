title: "How Synthetic Commission Cycles Work"
category: "broker_faq"
---
On this synthetic reference platform, a broker's commission for a given period is marked
available once it has been earned but not yet requested, pending while it is still being
finalized, or paid once a synthetic payment request has been completed. A broker can ask the
Broker Services Agent to register a synthetic commission-payment request once a commission is
available. This document is general background information only; the real synthetic status for
a specific broker and period always comes from a Tool result, never from this document.
